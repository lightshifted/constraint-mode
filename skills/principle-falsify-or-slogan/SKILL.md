# Falsify or it is a slogan

A constraint without a kill test is a slogan. Slogans survive every checkpoint, which is how they survive for years.

**When:** Accepting, repeating, or planning against a nominated constraint.

**Do:**
- Restate the claim as a mechanism.
- State the opposite claim: what is true instead if this factor is not binding.
- Name the cheapest observable that separates the two. Queue depth, cycle time, conversion, reply rate, runway, a blocked dependency.
- Set a check date or a triggering event. The observable and the date both go in the card.
- No observable exists, label the constraint `guess` and make instrumenting it the relief move.

**Refuse:**
- "Execution", "culture", "alignment", "focus" with no mechanism attached.
- "We will know it when we feel it."
- A falsifier that cannot fire before the check date. An untestable test is the slogan wearing a lab coat.

**Test:** Name the evidence, and the date, that would make you abandon this constraint. If you cannot, you are holding a slogan.
