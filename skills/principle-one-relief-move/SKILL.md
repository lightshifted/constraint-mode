# One relief move

Diagnosis without a single committed action is incomplete. A portfolio of bets is not focus, it is a hedge against having decided.

**When:** Converting a constraint into work, ending a checkpoint, or allocating the period's hours, budget, and agents.

**Do:**
- Commit one move that acts on the constraint mechanism.
- Prefer the smallest move that could change the falsifier before the check date.
- Define done as an observable result, not effort spent.
- Name what gets no attention while it runs. A parallel track needs an explicit exception from the owner and a stated cost to constraint relief.
- A mid-period replacement stops the active move. Supporting steps may serve the active move; they are not a second move.

**Refuse:**
- Ending on analysis when the owner asked what to do.
- Bundling several moves so that none of them is binding.
- "We can do both" with no cost statement.
- Starting a new move while the active one is still running without an explicit owner swap.

**Test:** Where does the next scarce hour go? If the answer is plural, you still have a portfolio.
